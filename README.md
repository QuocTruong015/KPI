## run project
1. Backend
   ```npm run dev or node server.js```
2. Postman
   POST: http://localhost:3000/kpi-combined?month=7&year=2025
   Param: month, year
   Body: Form data : input 6 file to calculate kpi
    + profit file:                  E-commerce
    + target_file:                  Project Management KPI_generate
    + ucs_2025:                     UCS_2025
    + daisy_file :                  Daisy Poster
    + ucs_poster_file:              UCS_Poster 2025
    + ucs_seller_management_file :  UCS_Seller Management
3. Output
   - Kết quả tính được trả về trong thư mục exports của dự án
